# Support

This is a community-maintained documentation project without hosted support, response-time guarantees, or consulting commitments.

- Use a GitHub issue for unclear, outdated, contradictory, or unsafe guidance.
- Use a core proposal for new universal guidance, adoption behavior, or cross-document
  changes.
- Use a profile request for technology-specific practices that should apply across projects.
- Use a question issue for a narrow question about applying or contributing to this
  playbook.
- Use a pull request for a concrete reviewed improvement.
- Use GitHub private vulnerability reporting for sensitive security concerns.

Questions about a consumer project's code, deployment, or agent runtime belong in that project's support channel unless the problem is caused by this playbook.

Public participation does not create a response-time, implementation, review, or merge
promise. Broad proposals and profiles require accepted issue scope before implementation.

Never include credentials, authorization headers, cookies, private logs, personal data, or confidential repository content in a public issue.
